A Python program — standard library only, no network — that writes one word to /output/entry.txt: "sramadhan-07", the entrant's own make.fun username, which is by definition the entry for this competition. The word is 12 characters, inside the competition's gate of one word of 1 to 30 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
